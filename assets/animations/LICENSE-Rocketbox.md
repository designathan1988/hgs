# Animações capturadas: Microsoft Rocketbox

`rocketbox.json` e `rocketbox.bin` são derivados das animações de
[Microsoft Rocketbox Avatar Library](https://github.com/microsoft/Microsoft-Rocketbox)
(pasta `Assets/Animations`), convertidas e redirecionadas para o esqueleto deste
projeto por `tools/import-rocketbox.mjs`. A lista de arquivos de origem de cada
clipe está no campo `file` de `rocketbox.json`.

Citação pedida pelos autores: Gonzalez-Franco et al., "The Rocketbox library and
the utility of freely available rigged avatars", Frontiers in Virtual Reality,
2020, doi:10.3389/frvir.2020.561558.
